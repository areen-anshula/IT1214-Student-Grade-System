<h1><b>IT1214-Student-Grade-System</b></h1>
<b><h2>=== Student Grade System ===</h2></b>
A private educational institute currently records student marks manually using paper records and spreadsheets. The institute has decided to develop a Student Grade Management System. The system should allow teachers to store student information digitally and manage academic records more effectively.

<hr>

<h1>How to Run</h1>

## Prerequisites

Make sure you have the following installed on your system:

* Java Development Kit (JDK) 8 or later
* A Java IDE such as IntelliJ IDEA, Eclipse, or VS Code (optional)

## Running the Program

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/student-grading-system.git
cd student-grading-system
```

### 2. Compile the Source Code

Open a terminal in the project directory and run:

```bash
javac StudentGradingSystem.java
```

### 3. Execute the Program

Run the compiled application using:

```bash
java StudentGradingSystem
```

## Features Available

After launching the application, you can:

1. Create a student record
2. View all student records
3. Search for a student by ID
4. Edit student details and marks
5. Delete a student record
6. Exit the application

## Notes

* The system can store up to **10 student records**.
* Each student contains:

  * Student ID
  * Student Name
  * Marks for 5 subjects
  * Automatically calculated average mark
* Input validation is included for menu selections to prevent invalid entries.
